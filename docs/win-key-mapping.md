# Android 悬浮窗的 Win 模组按键映射

基于 Android 1.2.1，版本号 1.2.2（10202）。此次仅更新悬浮窗及其内置输入兼容层；保持 1.2.1 的 SDK、引导、变速、自由相机及其它模组载荷不变。不修改第三方 Win 模组 DLL。

## 使用

1. 覆盖安装新版 APK，在「加载器」执行「安装 / 更新悬浮窗」，然后完全重启游戏。
2. 打开游戏悬浮窗，在「功能类」或「其他类」选择已运行的模组。
3. 「Win 模组按键映射」按该模组当前配置显示快捷键。点「点按」发送一次；长按型功能使用「保持按住」，再点「松开」。关闭面板、切换页面、失焦或开始文字输入会释放虚拟按键。
4. 第三方模组可以输入自定义按键，例如 `H`、`F3`、`Ctrl+H`、`LeftAlt+H`，点保存。一个模组可保存一个自定义组合键（最多四个不同键）。此映射只决定按钮发送什么键，不会替模组修改快捷键配置；两者需要一致。

已提供默认动作：隐藏 HUD、角色半透明、PVE 波次、商店筹码看板清空、星币商店一键购买、PVE 面板三组开关、更新通知。默认动作读取目标模组配置，不硬编码覆盖玩家改键。变速与自由相机继续使用 Android 专用控制，不提供 Win 按键映射。

隐藏 HUD 改用原模组的按键状态机，不再创建另一个反射 hider。`pressMode=hold` 时需要持续保持按住，达到原配置 `holdSeconds` 后生效；`pressMode=toggle` 时点按切换。功能开关仅启用监听，不等于已经隐藏 HUD。

## 兼容边界

- 适配调用 `CesiumLoader.SDK.Inputs.InputService` 的模组。直接读取 Unity Input、Windows 原生按键或其它输入系统的模组不在此入口范围内。
- 虚拟按键是共享键盘。同键模组可能一起响应；需要在模组配置中改为不同按键。按钮旁有明确提示，不宣称按模组隔离。
- 不模拟鼠标、滚轮或游戏自身的移动轴；真实输入照常传给原后端。角色、商店等功能仍受原模组的启用状态和游戏场景条件限制。
- 聊天输入、SDK 键盘独占和 SDK 模组窗口打开时，不绕过输入屏蔽。若其他模组替换了输入后端，显示提示并释放虚拟输入，不反复强夺后端。
- 当前包保留 1.2.1 已有的全部载荷，包括此前的卡面兼容实现；本次没有额外移植或重编译这些模组。以后升级官方加载器时，应按其实际 Android 支持情况迁移，不能把按键桥接等同于所有 DLL 完整跨平台兼容。

## 实现

`VirtualKeyState` 管理按键源和帧快照；输入从下一帧生效，同帧重复读取不会消费边沿事件。不同来源共享修饰键时互不释放。`VirtualKeyboard` 包装当前 `IInputBackend`，通过公开 `InputService.SetBackend` 安装，在卸载时有条件恢复原后端。状态保存在兼容层内，不改 SDK 二进制。

自定义映射保存在悬浮窗配置 `configs/CesiumOverlayMod.json` 的 `keymap.<ModId>` 字段。通过模组页卸载后该集中配置仍保留。
