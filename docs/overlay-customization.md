# 悬浮窗外观与分组（1.2.4）

覆盖安装 APK 后，在「加载器」执行「安装 / 更新悬浮窗」，完全重启游戏。

## 游戏内操作

- 点击圆形边缘入口展开。独立侧栏与圆角正方形主框等高，中间空隙可以看到游戏画面。
- 点击两个面板以外的空白处收起；该触摸继续交给游戏。侧栏不再提供收起按钮。
- 圆形入口闲置 5 秒或点击外部后变为半透明，并半隐藏到最近的左右屏幕边缘。触摸可唤醒，拖动松手后重新吸附；不会在拖动中自动滑回边缘。
- 侧栏「设置」调整面板不透明度：拖动滑块，范围 25%–100%，支持恢复默认 50%。保存立即生效，失败时显示提示。
- 变速页「恢复原速」保存当前倍率并恢复 1.0x；「启用原变速」重新启用上次倍率。重新选倍率会更新记忆；每次启动游戏仍默认 1.0x，不从历史配置自动加速。

## APK 设置

「设置 → 悬浮窗」保留最多 8 个分组的新增、改名、排序、删除和模组分配；未分配模组归入「其他」。变速固定为独立入口。

大小改为统一缩放，主框始终是正方形，侧栏与主框保持等高。可调整为默认大小的 65%–160%，实际受屏幕可用区域限制；恢复默认大小不影响分组或透明度。旧版分别保存的高度不再决定布局。

透明度已移到游戏内，APK 不再显示透明度控制。APK 保存分组和大小时合并游戏端最新透明度，避免旧的编辑页覆盖游戏内新设置。

离线修改保存在 APK，连接 Shizuku / Root 并安装加载器后，重开应用重试同步。每个加载器目录保留各自设置。点「重新读取」会放弃未保存编辑并读取当前设置。

## 数据与兼容

继续使用加载器 `data/toys-overlay.txt` 的 version=1 协议，保留 opacity / width / height / group 字段。height 仅为旧协议兼容字段，新布局以 width 作为统一大小。游戏端仅合并 opacity，APK 端合并分组与大小，双方均保留另一端控制的字段。

未修改 SDK、安卓专用变速 DLL、自由相机 DLL 或其他 Win 模组 DLL。窗口的变速按钮继续调用原有唯一变速控制通道，不增加第二个每帧写倍率的控制器。


独立开关动画：侧栏先滑出淡入，主框稍后缩放弹出；收起时主框先缩小淡出，侧栏随后退回。两条动画均使用真实时间，支持中途反向切换。未保存过透明度时默认 50%，已有保存值继续保留，可点恢复默认改为 50%。
