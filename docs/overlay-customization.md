# 悬浮窗外观与分组

1. 覆盖安装 1.2.3，在「加载器」执行「安装 / 更新悬浮窗」，完全重启游戏。
2. 游戏内点击边缘入口，窗口以缩放和淡入动画展开；侧栏「收起」缩回入口。
3. 左侧停靠时拖右下角，右侧停靠时拖左下角，即可调整宽高。拖动中显示缩放预览，松开后按新宽高重新排版。旋转屏幕或失焦会取消未完成拖拽。
4. 侧栏可独立滚动，包含变速、自定义分组、其他、默认大小和收起。侧栏「默认大小」立即恢复宽高，不改变分组和透明度。

APK「设置 → 悬浮窗」可调整不透明度、宽高和分组。创建最多 8 个分组，改名、上移、下移或删除；给每个模组选择一个分组。变速始终使用固定入口，未分组模组显示在其他。停用或尚未加载的模组可以预先分组，运行时仅展示实际注册的模组。

点击「保存并同步」后设置约一秒后被新版游戏悬浮窗读取。没有连接 Root / Shizuku 时，本地保存并等待重新连接后重开应用。切换加载器目录使用各自的设置。同步失败时页面显示原因；不要把本地保存提示当成游戏已经应用。

游戏拖拽与 APK 使用同一个游戏端设置文件。APK「重新读取」可读取游戏中保存的大小，但会丢弃当前页面未保存的改动。APK「恢复默认大小」把宽高调回 100%，点击保存后生效；不会清除分组或改变不透明度。

宽高百分比以原半屏窗口为基准，最终尺寸仍受屏幕边界和可操作的最小尺寸限制。透明度作用于整个面板，避免底板、文字和按钮出现不同步的淡入淡出。

设置协议存储在加载器 `data/toys-overlay.txt`：`version=1`、`opacity`、`width`、`height` 及若干 `group=<UTF-8 名称的 Base64>|<逗号分隔的 ModId>`。APK 经既有原子写入通道同步；游戏拖角结束时仅合并最新文件中的大小，保留分组与不透明度。
