# 悬浮窗外观与分组（1.0.0）

覆盖安装 APK 后，在「加载器」执行「安装 / 更新悬浮窗」，完全重启游戏。

## 形态与交互

- 初始为贴边圆角方块，中心是像素头像入口。支持拖拽；松手后按水平位置就近吸附到左/右边缘，不会停在中间。
- 贴边一侧的上下两个圆角变为直角，另一侧保留圆角；拖动到半空时四角全部恢复圆角，吸附落位后才重新卡进边缘。
- 点击入口展开为竖向长条，长条与右侧详情面板等高，中间留 10u 空隙可以看到游戏画面。长条内自上而下是六个 Material 图标：功能、变速、模组配置、设置、控制台、关于。
- 点击两个面板以外的空白处收起，该次触摸用于收起面板，不透传给游戏。
- 入口闲置 5 秒后淡出到设定浓度；触摸、拖动或展开会立刻唤醒。淡出下限是 2% 不透明度——完全透明后 FairyGUI 不再命中测试，就点不醒了。
- 手机端左右两侧展开后停在屏幕垂直居中，位置固定；平板端允许两侧高度不同，并在长条上下预留额外的高度。
- 展开位置会被记住（`center=` 字段），第二次打开沿用上次位置。

## 六页内容

| 页 | 内容 |
| --- | --- |
| 功能 | 「快捷开关」（mod 注册的开关/按钮）+「按键映射」（自带 Win 快捷键的模组，已在前一段出现过的不重复列出） |
| 变速 | 当前倍率大号读数、±0.5x 步进、1.0/1.5/2/3/5x 预设、「恢复原速 / 启用原变速」 |
| 模组配置 | 全部已加载模组的纯导航列表，点一行进入该模组的选项与按键映射 |
| 设置 | 面板不透明度、字体大小、闲置淡出时间与浓度、分组一览、当前深浅色方案 |
| 控制台 | 最近 40 行日志，支持「导出日志」到 `data/toys-log-<时间戳>.log` |
| 关于 | 名称、版本、使用说明、已加载模组数量 |

「功能」页只显示两类内容，其余模组不再列出——没有快捷键也没有注册快捷项的模组不会出现在这里。要新增快捷项见 [`overlay-shortcuts.md`](overlay-shortcuts.md)。

「模组配置」页没有开关：点一行就是进该模组的详情，总开关在「功能」页那一行上。

变速页在倍率大于 1x 时显示「恢复原速（1.0x）」，点击后暂停加速；回到 1x 后显示「启用原变速」及上次成功选择的倍率，再次点击恢复。切换预设或步进会记住新倍率；选择 1x 不清除倍率记忆。没有可恢复倍率时按钮不可用，游戏启动仍保持 1x。

## 动画

- 展开：宽度先到位（240ms `CubicOut`），高度随后（320ms），入口位移 400ms `QuartOut`；侧栏淡入 180ms（延迟 140ms），面板滑入 300ms（延迟 220ms）。
- 收起：面板先退（120ms `CubicIn`），随后长条缩回（260ms）。
- 圆角在吸附 / 脱开时用 180ms `SineInOut` 过渡。
- 全部动画走 `Time.unscaledDeltaTime` 手写补间，不用 `GTween`：本模组自身就在改 `Time.timeScale`，且 `Build()` 会整体销毁重建节点树，挂着 GTween 会留悬空引用。

## 大小与不透明度

游戏内「设置」页只保留**不透明度**（50% / 70% / 85% / 100% 四档，默认 50%）与**字体大小**（0.85 / 1 / 1.15 / 1.3 四档）。原来的「窄一点 / 宽一点 / 恢复默认大小」已移除：面板尺寸由六页内容自动决定，手动缩放只会让行放不下。

面板的统一尺寸改由 APK 侧的「设置 → 悬浮窗」单个滑杆控制（默认大小的 65%–160%），实际受屏幕可用区域限制。

## 主题

跟随手机深浅色，并取 Material You 动态色。实现方式：APK 侧把**浅色与深色两套** token 同时写进 `data/toys-appearance.txt`，游戏内读取自己解析到的方案对应的那一块。

之所以两套都写：玩家可能在游戏运行时从快捷设置切深浅色，那一刻 APK 没在跑，没法重写文件。

```
system            ← 第 0 行：system | light | dark
dark              ← 第 1 行：已解析出的结果
light.surface=#FFE6E0E9
dark.surface=#FF141218
primary=#FFD0BCFF ← 无前缀的 token 优先级最高
```

无前缀的 `token=` 行会覆盖两套方案，留给调试与手动调色用。没有覆盖时使用内置 M3 基线色。

## 设置协议

`data/toys-overlay.txt`（version=1，UTF-8 无 BOM）：

```
version=1
opacity=0.50      # 0.25 – 1.00
width=1.00        # 0.65 – 1.60，统一大小
height=1.00       # 旧协议兼容字段，新布局以 width 为准
font=1.00         # 0.80 – 1.40，面板文字缩放
idle=5.00         # 0 – 60，闲置多少秒后淡出；0 表示不淡出
idleOpacity=0.35  # 0.15 – 1.00，淡出后的浓度
previousSpeed=1.0 # 1.0 – 10.0，供「恢复倍速」使用
center=0.42       # 0 – 1，展开时的垂直位置；从没拖动过则不写这一行
group=<base64(name)>|<comma-separated-mod-ids>
```

最多 8 个分组、每组最多 128 个 id；id 只允许 `[A-Za-z0-9._-]` 且最长 128 字符；组名最长 30 字符。`SpeedHackMod` 不参与分组。

`center` 不写表示「从未移动过」，读取时保持 `-1`；把它钳到 0 会把面板钉在屏幕顶端，所以负值是有效语义。

`toys-appearance.txt` 前两行格式不变（`system|light|dark` + 解析结果），第三行起是 token，详见上节。

## 数据同步

- 游戏内改动（不透明度、字体、闲置淡出、位置、变速记忆）立即写入 `data/toys-overlay.txt`，写入走 `.game-tmp` + `File.Replace` 原子替换。
- 写之前会先重读文件再改单个字段，避免把 APK 并发写入的分组覆盖掉。
- APK 侧「保存并同步」记录实际编辑过的分组、统一大小、字体和闲置选项；未编辑字段沿用最新游戏值。`opacity`、`center`、`previousSpeed` 始终取游戏端最新值，旧草稿不会把它们重置。
- 待同步草稿重新读取时，会合入最新游戏设置但保留待提交的编辑；离线多次保存不会丢掉之前排队的字段。旧版本排队草稿兼容为大小与分组编辑。
- 离线修改保存在 APK，连接 Shizuku / Root 后重开应用重试同步；每个加载器目录各自保留设置。「重新读取」放弃未保存编辑。

## 实现约束

- 未修改 SDK、安卓专用变速 DLL、自由相机 DLL 或其他 Win 模组 DLL。变速按钮统一走 `SpeedPanel.Choose` → `SpeedResumeState.Choose` → `LocalSpeed.Choose`，不引入第二个每帧写倍率的控制器。
- 面板与入口的圆角是 CPU 侧 SDF 栅格化成**一整块**纹理，不用 `GGraph.DrawRoundRect`：后者走三角形网格栅格化，无边缘过滤，1.5× 缩放下圆角有明显锯齿。也不再把形状切成四个角片拼贴——切片的切线处会留下发丝级接缝，动画中尤其明显。
- 整块纹理按「即将绘制出来的尺寸」烘焙，一次烘焙复用到盒子超出 15%（1.15 倍）才重烘，所以一段展开动画只重烘十来次而不是每帧一次；静置时再按 1 纹理像素 = 1 屏幕像素精确重烘一次。圆角半径与盒子取自同一时刻，弧线在纹理空间里是正圆，即使纹理被非等比拉伸也不会变成椭圆。细节见 `mods/CesiumOverlayMod/OverlaySkin.cs` 与 `OverlayRaster.cs` 的文件头注释。
