# Astral Party Toys Android 1.3.6

修复 4399 等非 `com.feimo.*` 前缀的渠道服包体（如 `com.jxpd.feimo.m4399`）在设备/模拟器中无法被检测到的问题，并包含 1.3.5 之后的界面稳定性修复。应用版本 1.3.6，versionCode 10306，沿用原正式签名。

## 修复与改进

- **扩展全渠道包名识别**：`AndroidPaths` 与本地程序集补丁器 `AssemblyPatch` 新增支持 `com.jxpd.feimo.*`（如 4399 渠道服 `com.jxpd.feimo.m4399`）、`com.astralparty.feimo.*`、`com.jxpd.*`、`com.astralparty.*` 与 `com.tencent.tmgp.(feimo.)?(astralparty|jxpd).*` 等渠道包名格式（仍排除日服 `jpn`）。
- **修复包体扫描遗漏与模拟器兼容**：`LoaderInstaller.installedGamePackages()` 不再仅按 `com.feimo` 过滤 `pm list packages`，改为拉取完整包列表后按规则筛选，并在部分模拟器不支持 `--user current` 参数时自动回退到 `pm list packages`（`pm path` 同步兜底）。
- **界面稳定性（合自上游修复）**：旋转屏幕或切换深色模式时保留配置编辑器与页面状态，并为安装日志增加上限保护。
