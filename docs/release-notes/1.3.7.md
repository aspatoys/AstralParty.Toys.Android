# Astral Party Toys Android 1.3.7

在「加载器」页新增手动选择包体与本地导入 `higashitaniyume/CesiumLoader` 发布包 ZIP 功能。应用版本 1.3.7，versionCode 10307，沿用原正式签名。

## 新增功能

- **自定义选择游戏包体**：「加载器 → 游戏资源」新增「选择包体」按钮，弹窗支持列出并搜索设备上已安装的第三方应用（自动识别到的游戏包名优先置顶），也支持直接手动输入任意合法 Android 包名作为目标游戏。
- **导入 CesiumLoader 发布包**：在「安装内置加载器」按钮下方新增「导入发布包」按钮，可直接从手机文件管理器选择 `higashitaniyume/CesiumLoader` 发布的 `cesium-loader-*.zip` 压缩包，校验清单与 SHA-256 后本地更新托管 SDK 与模组，并保留 Android 悬浮窗、变速、自由相机及已有用户配置。
