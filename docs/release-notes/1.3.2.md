# Astral Party Toys Android 1.3.2

合入协作者 feat/overlay-1.0.0 分支的悬浮窗 1.0.0 改版。应用版本 1.3.2，versionCode 10302，沿用原正式签名。

## 悬浮窗外观与交互

- 更新为功能、变速、模组配置、设置、控制台、关于六页导航，使用 Material 图标与独立侧栏。
- 圆角采用抗锯齿纹理，展开、收起与贴边形变使用独立补间动画。
- 同步浅色、深色两套 Material You 色板，跟随手机主题。
- 支持统一大小、字体大小、闲置淡出时间与淡出浓度；原 version=1 配置继续兼容。
- 增加功能页快捷项注册 API，保留安卓适配的变速和自由相机入口。
- 变速按钮支持「恢复原速 / 重新启用上次倍率」往返切换；倍率记忆取最近成功选择的值，改选倍率及手动点 1x 后都可恢复。

## 兼容与安装

- 保留 1.3.1 的重复目录整理、模组原停用状态、本地配置和恢复副本保护。
- 本次重编 CesiumAndroidApi 与悬浮窗，SDK、Android 引导、游戏注入、变速、相机及卡面适配继续使用现有载荷。
- 修复 APK 过期草稿覆盖游戏内位置、倍率记忆和未编辑外观设置的问题；离线保存按字段合并并兼容旧草稿。
- 覆盖安装 APK 后，到「加载器 → 内置悬浮窗」执行「安装 / 更新悬浮窗」，完全重启游戏。
- 透明度等外观调整在游戏内设置页，统一大小和分组仍可在 APK 设置管理；具体形态见 overlay-customization.md。

协作者源码来自提交 70e3fb3（feat/overlay-1.0.0），原作者声明和许可证保留。
