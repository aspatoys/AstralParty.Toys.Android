# Astral Party Toys Android 1.2.1

功能与 1.2.0 一致：自定义卡牌、模组市场、加载器安装与游戏内悬浮窗。本版重新构建发行包，随包加载器、默认卡面与签名均与 1.2.0 相同。

## 升级

1. 直接覆盖安装 `aspatoys-1.2.1.apk`，可沿同一证书从 1.1.2–1.2.0 升级。
2. 已导入的卡牌方案、模组与配置保留在加载器目录，无需重新导入。

## 签名

1.2.1 沿用 1.1.2 的正式私钥签名。按用户选择，公开验证证书和 RSA 公钥，不公开私钥。

- APK 证书 SHA-256：`7cdb0644cd2bc4370152643950dde7b8cbf99ba4f770e094e9ecb775ca392bcc`
- `aspatoys-signing-certificate.pem`：验证证书。
- `aspatoys-signing-public-key.pem`：验证公钥。
- 验证方法见仓库 `docs/signing/README.md`。

早期正式版 1.1.0 / 1.1.1 及测试包签名不同，不能直接覆盖，需要先保存设置、卸载旧版再安装。
