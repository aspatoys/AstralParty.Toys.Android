# Astral Party Toys Android 1.5.1

应用版本 1.5.1，versionCode 10501，沿用原正式签名，可从 1.1.2 及以上版本覆盖升级。

## 变更内容

- 移动端托管载荷包改名为 `cesium-loader-mobile-managed-1.5.1.zip`，并随包内置移动版官方模组。
- 固定 `CesiumLoader.Mobile.API` 程序集名称，保证移动端扩展功能在各类构建下正常识别与启用。
- 当游戏进程预先创建了只读的 `CesiumLoader` 目录导致无法写入或删除时，直接给出清晰的原因与处理建议。

## 安装

1. 覆盖安装 `aspatoys-1.5.1.apk`。
2. 如从 1.4.x 及更早版本升级，请在加载器页重新安装一次加载器，然后完全重启游戏。
