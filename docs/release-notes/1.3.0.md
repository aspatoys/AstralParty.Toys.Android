# Astral Party Toys Android 1.3.0

新增官方加载器更新与 APK 内软件更新，沿用原签名，versionCode 为 10300。

## 加载器更新

- 模组页增加 CesiumLoader 更新卡片：显示已装版本、检查 GitHub 最新版、从 GitHub 更新及发行页面入口。
- 与 Win 版使用同一个 CesiumLoader 仓库、version.json 和 Release ZIP，并提供相同的直连、gh-proxy.com、ghfast.top、自定义镜像选项。
- 校验整包 SHA-256 和发行清单内的文件哈希，只更新 Android 可用的托管 SDK 与模组。Android 引导、游戏注入、离线恢复包及用户集中配置保持原样。
- 官方包中的 SpeedHackMod、FreeCameraMod 和 CesiumOverlayMod 被排除，保留安卓适配版本，不覆盖它们的配置。
- 保持原有模组停用状态；写入异常时回滚本次文件更新。更新前完全退出游戏，更新后重启游戏。

## 软件本体更新

- 设置新增「软件更新」，支持手动检查、下载、安装，显示版本、更新日志和进度。
- 支持启动时自动检查、自动下载，以及前台下载完成后自动打开系统安装界面；均可分别关闭。
- 从 Android 仓库获取 APK，校验 SHA-256、包名、递增版本和正式签名证书后才允许安装。
- Android 仍要求安装确认；首次需要允许本应用安装未知来源应用。更新采用覆盖安装，不卸载或清空数据。
- 默认通过与 Win 版一致的 gh-proxy.com 镜像访问 GitHub；可在软件更新设置切换直连或其他镜像。

首次部署加载器仍使用随包已验证版本。联网更新不会替换 Windows 原生引导；不兼容 Android 的 LanguageUnlockMod 继续跳过。
