# Astral Party Toys Android 1.2.2

基于 1.2.1 增加游戏内悬浮窗的 Win 模组按键映射。沿用原签名，versionCode 为 10202。

- 通过 SDK 公开输入后端接入虚拟键盘，不修改目标 Win 模组或 SDK DLL。
- 支持点按、保持按住/松开、组合键，以及每个模组一个可保存的手动映射。
- 隐藏 HUD、角色半透明、波次预告、商店看板、一键购买、PVE 面板与更新通知，按各自现有配置生成按钮。
- 关闭面板、切页、界面重建、失焦或文字输入时释放虚拟按键；尊重 SDK 输入独占与窗口屏蔽。
- 安卓变速与双指自由相机继续使用专用控制，本次不修改两者。

安装后在「加载器」执行「安装 / 更新悬浮窗」，完全重启游戏。在悬浮窗内选择模组，找到「Win 模组按键映射」。详见 `docs/win-key-mapping.md`。

输入是共享键盘，同键模组可能同时响应。第三方模组须使用 SDK InputService 才能接入；本功能不模拟游戏自身的 Unity 输入或 Windows 原生 API。
