# Astral Party Toys Android 1.4.2

修复更新加载器后安卓引导没有一起更新，导致模组配置每次启动都被搬回旧目录的问题。应用版本 1.4.2，versionCode 10402，沿用原正式签名。

## 更新加载器

- 更新或导入加载器时，安卓引导（`bootstrap/CesiumLoader.Android.Bootstrap.dll`）现在与 SDK 一起更新，两者始终来自同一个 App 版本，不会再出现「新 SDK + 旧引导」。
- 引导、SDK 与模组在同一个事务里发布：任何一步失败都会一起回滚到更新前的状态。

## 模组配置

- 加载器启动时会把旧的集中目录 `configs/` 改名为 `configs.bak`，模组只读写自己目录里的 `config.json`。
- 之前的版本每次启动会把 `mods/<Id>/config.json` 改名成 `config.json.bak`，玩家设置可能还留在 `configs.bak/<Id>.json`；需要时把它改名成 `mods/<Id>/config.json` 即可沿用。

## 安装

1. 覆盖安装 `aspatoys-1.4.2.apk`，可沿同一证书从 1.1.2 起升级。
2. 装好后在加载器页重新安装一次加载器（或导入同一个发布包），让新的安卓引导落盘，然后完全重启游戏。
