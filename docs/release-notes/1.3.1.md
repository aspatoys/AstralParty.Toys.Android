# Astral Party Toys Android 1.3.1

修复重复模组目录导致启用、停用失败的问题，沿用原正式签名。versionCode 为 10301。

## 模组切换

- 自动整理启用目录和停用目录中的同名模组，切换后只在目标状态保留一份可加载主体。
- 兼容空目录和旧平铺 DLL 与目录混合的安装布局，避免移动后出现嵌套目录或重复加载。
- 集中 `configs/` 不修改；重复模组的本地配置、独有资源和原始副本保留，整理备份位于加载器目录内的非模组扫描位置。
- 原有普通切换和重复点击继续可用；整理失败会保留恢复数据并显示错误。

## 安装内置加载器

- 已停用的内置模组继续写入停用位置，原启用模组保持启用，新模组沿用安装默认行为。
- 已有重复副本优先保持停用并整理，兼容旧平铺安装，避免重新生成启用副本。
- 保留本地配置和皮肤、预设等用户资源；安卓适配悬浮窗、变速和自由相机采用相同状态规则。

操作前完全退出游戏，完成后重新启动。模组整理不改变 1.3.0 的完整卸载行为：确认卸载仍会删除加载器目录及其中的配置和备份。
