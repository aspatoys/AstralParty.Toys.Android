# Astral Party Toys Android 1.4.1

模组配置改为写在模组自己的目录里，并随包携带 CesiumLoader 4.0.0。应用版本 1.4.1，versionCode 10401，沿用原正式签名。

## 模组配置

- 模组配置统一放在模组自己的目录里：`mods/<ModId>/config.json`，停用的模组是 `disabled_mods/<ModId>/config.json`。模组页的配置编辑、卡面皮肤应用与模组删除提示都读写这一份，改完在游戏里立即生效。
- 旧的集中目录 `configs/` 不再使用：加载器启动时把它整个改名为 `configs.bak`，里面的设置不再生效。要沿用旧值，把 `configs.bak/<ModId>.json` 改名成 `mods/<ModId>/config.json` 即可。
- 导入或更新模组不会覆盖已有的 `config.json`；删除模组时，它目录里的 `config.json` 会一起删除。

## 加载器

- 随包加载器升级到 CesiumLoader 4.0.0（SDK 与引导同步），与上面的配置位置一致。已经装过旧版加载器的，在加载器页更新一次即可。

## 安装

1. 覆盖安装 `aspatoys-1.4.1.apk`，可沿同一证书从 1.1.2 起升级。
2. 已安装的加载器、模组、卡牌方案保留在加载器目录，无需重新导入。
3. 加载器更新后旧配置不会自动迁移，按上面「模组配置」一节手动改名。
