# Astral Party Toys Android 1.2.3

基于 1.2.2 更新游戏内悬浮窗，沿用原签名，versionCode 为 10203。

- 参照用户演示，面板从边缘入口放大弹出，收起时缩小回到入口；支持中途反向切换，动画使用真实时间，不受变速影响。
- 顶部分页改为可独立滚动的侧栏，固定保留变速与其他入口。
- 拖拽面板底角调整宽高，松开后重新排版并保存。左侧停靠时拖右下角，右侧停靠时拖左下角；窗口尺寸限制在屏幕可用区域内。
- APK「设置 → 悬浮窗」支持添加、改名、排序、删除分组，将已安装模组分配到分组；未分配模组归入其他。
- APK 可调整面板不透明度（25%–100%）、宽度和高度（默认大小的 65%–160%，受屏幕边界限制）。APK 和游戏侧栏均有恢复默认大小入口。
- 设置保存后通过已有 Shizuku / Root 通道同步；离线修改保存在 APK，连接后重开应用会重试。游戏内拖拽大小也可在 APK 中重新读取。

安装后执行「加载器 → 安装 / 更新悬浮窗」，完全重启游戏。旧版按键映射、安卓变速和双指自由相机继续保留。
