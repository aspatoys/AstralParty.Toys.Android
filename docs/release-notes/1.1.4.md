# Astral Party Toys Android 1.1.4

修复部分设备安装后游戏正常启动、但模组全部不加载且没有引导日志的问题。包含 TenkinMori 已合入上游的文件属主修复，并补齐写入、迁移与校验路径。

## 修复

- 暂存的 DLL、配置及缓存包在发布前交回游戏 uid，并验证结果。chown 失败或 stat 读不到属主时明确报错，不再显示安装成功。
- 重复安装修复 1.1.2 / 1.1.3 遗留的加载器目录、子目录、文件和游戏缓存包属主；无需反复卸载游戏或手动执行命令。
- mkdir -p 创建的中间目录一并处理；移动已安装模组前检查整个目录树。
- 原包还原及中断恢复的写入路径同样校验属主；校验失败保留诊断与原版备份。
- 不跨 Shizuku 重连或游戏重装缓存 uid。安装过程中禁用提权方式切换。
- 增加写入失败保留旧 DLL、非 Root 通道、旧安装迁移、真实游戏缓存安装与回滚测试；真实资源测试不再因缺少本地参考工程而静默跳过。

## 升级与修复步骤

1. 覆盖安装 `aspatoys-1.1.4.apk`。沿用 1.1.2 起的正式签名，versionCode 为 10104。
2. 完全退出游戏。在「加载器」页选择 Root 模式，或使用以 Root 启动并授权的 Shizuku。
3. 点击「安装加载器」，等待日志显示属主校验与安装通过，再重新启动游戏。

受系统限制的普通 Shizuku（uid 2000）不能修改文件属主。只有文件本来就由系统映射为游戏 uid、且允许写入时才能使用；本版不会绕过系统限制或将失败伪装成成功。
