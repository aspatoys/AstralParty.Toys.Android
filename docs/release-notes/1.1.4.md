# Astral Party Toys Android 1.1.4

本次更新修复加载器安装中的文件权限问题，支持在已验证设备上通过 **非 Root Shizuku** 正常安装和加载模组，同时保留 Root 模式的文件属主修复。

> 本页 APK 是 **1.1.4 的 Shizuku 修订版**。版本号和 versionCode 保持不变，请通过文件名与 SHA-256 区分此前发布的 1.1.4。

## 更新内容

### 修复非 Root Shizuku 安装

- 修复将“文件属主必须等于游戏 uid”作为非 Root 安装硬条件的问题。部分设备允许游戏读取由 Shizuku 创建的文件，旧校验会错误阻止安装。
- 非 Root 模式改为检查路径的实际访问能力，不再尝试依赖该通道无法完成的 chown。
- DLL 和配置文件写入暂存文件后，先校验 SHA-256，再替换目标；替换后再次核对，避免静默写入损坏文件。
- 安装日志区分“Shizuku 目录访问已校验”和游戏实际加载结果，便于确认问题所在。

### 保留 Root 安装修复

- Root 模式仍会修复并严格校验文件属主。
- 重复安装可修复旧版遗留的加载器目录、子目录、文件及缓存包属主问题。
- 保留原包备份、缓存指纹校验及恢复机制；未知游戏缓存版本仍拒绝覆盖。

本版不包含 1.2.0 的自定义卡牌功能。

## 安装与升级

1. 下载并安装本页的 `aspatoys-1.1.4-shizuku.apk`。
2. 非 Root 用户先启动 Shizuku，并向 Astral Party Toys 授权。
3. 完全退出国服游戏，打开工具箱的「加载器」页，选择「Shizuku 模式」。Root 用户也可以继续使用 Root 模式。
4. 点击一次「安装加载器」，等待日志显示安装及写回校验通过。
5. 重新启动游戏，检查悬浮窗及模组是否正常加载。

**已经安装旧 1.1.4 的用户，也需要覆盖安装本次 APK，再执行一次「安装加载器」。仅更新工具箱不会自动更新游戏目录中的文件。**

本版沿用 1.1.2 起使用的正式签名，可覆盖安装使用该签名的版本，无需卸载或清除数据。更早版本或不同签名的测试包不属于这一覆盖升级范围。
