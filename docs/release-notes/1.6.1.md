# Astral Party Toys Android 1.6.1

应用版本 1.6.1，versionCode 10601，沿用原正式签名，可从 1.1.2 及以上版本（含 1.5.1 / 1.6.0）直接覆盖升级。

## 变更内容

- 修复 `1.6.0` 正式包打开闪退问题：将 `kotlin.**` 移出 R8 局部优化范围，避免 AGP 9.5.1 重打包破坏 `kotlin.text` 多文件门面类继承链导致启动时报 `IllegalAccessError`。
- CI 发行流程新增 Release APK DEX 跨包可见性校验，防止同类 R8 回归。
- 包含 `1.6.0` 的全部功能：自定义主页背景（图片/视频导入、60fps 保留与 EGL 降级转码、相册/文件选择、模组市场引导）与内置安卓悬浮窗 1.1.0 修复。

## 安装

1. 直接覆盖安装 `aspatoys-1.6.1.apk`。
2. 如从 1.4.x 及更早版本升级，请在加载器页重新安装一次加载器，然后完全重启游戏。
