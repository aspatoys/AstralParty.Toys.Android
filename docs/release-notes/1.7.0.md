# Astral Party Toys Android 1.7.0

应用版本 1.7.0，versionCode 10700，沿用原正式签名，可从 1.1.2 及以上版本直接覆盖升级。本版为预发布版本。

## 变更内容

- 修复部分设备上启动游戏后模组完全不加载的问题：加载器在确定模组目录时会调用一处运行时已裁剪的反射接口，异常逃出热更程序集的模块初始化，导致整份程序集加载失败。现在改为读取本进程自身信息，不再依赖任何引擎类型。
- 加载器目录存在但游戏无权写入时，不再改换到其他目录，模组照常从安装器投放的位置加载，只在日志里记录一条说明。
- 悬浮窗的模组归属识别改为缓存查找，并同时兼容旧程序集名；老载荷环境下的开关也能对应到正确的模组。
- 启动日志补充运行环境、进程与载荷信息：本地与 UTC 时间、进程号与包名、运行时版本、内核、API 与 SDK 及每个模组的路径、字节数与指纹，`mods` 与 `disabled_mods` 目录状态，逐个模组的加载顺序、入口数量与耗时，以及加载总耗时。
- 启动日志改为分段写入，某个模组导致进程退出时仍能看到它之前的记录；无法识别的 DLL 会单独标注为没有入口，不再静默跳过。

## 安装

1. 直接覆盖安装 `aspatoys-1.7.0.apk`。
2. 覆盖安装后请在加载器页重新安装一次加载器，让新的引导落盘，然后完全重启游戏。
3. 若仍有模组不加载，请把 `CesiumLoader/logs` 下最新的 `bootstrap-*.log` 一并反馈。
