# Astral Party Toys Android 1.6.2

应用版本 1.6.2，versionCode 10602，沿用原正式签名，可从 1.1.2 及以上版本直接覆盖升级。

## 变更内容

- 「自定义主页背景」新增显示模式切换：**填充**（默认，等比铺满并裁切多余部分，无黑边不变形）、**适应**（等比完整显示并纯黑留边）、**平铺**（原尺寸重复平铺）与**拉伸**（自由拉伸铺满）。
- 配合 `HomeBackgroundMod 1.2.2+` 修复超宽屏手机主页背景左右未铺满的问题；若已装旧版 Mod 会提示前往市场更新。

## 安装

1. 直接覆盖安装 `aspatoys-1.6.2.apk`。
2. 如需切换背景显示模式及超宽屏满屏适配，请在模组市场将 `HomeBackgroundMod` 更新至 `1.2.2` 及以上。
