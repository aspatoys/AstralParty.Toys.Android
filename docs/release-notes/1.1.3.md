# Astral Party Toys Android 1.1.3

本次更新优化了应用界面结构、设置分区与模组管理体验，全面适配 Material You 动态取色。

## 新增与改进

### 应用界面与主题
- **Material You 动态取色**：支持 Android 原生动态配色（Material You），界面随系统壁纸动态调整主色调。
- **界面结构优化**：移除顶栏冗余标题，增大内容显示区域；底部悬浮 Dock 改为半透明胶囊风格，沉浸感更强。

### 设置页面重构
- **分类导航与独立子页**：设置项按「外观与主题」、「背景设置」、「市场设置」、「语言设置」、「目录与存储」以及「关于」进行模块化分类，支持平滑手势滑动与系统返回键返回。
- **关于页面**：新增开发团队联系方式卡片（TenkinMori 与 囚魚玖 的 GitHub 和 Bilibili 主页链接），以及安卓版 Toys、桌面版 Toys 与 CesiumLoader 加载器的开源项目仓库直达卡片。

### 模组管理
- **独立模组配置页面**：模组设置由原有抽屉弹出改为独立页面，支持表单快速修改与原始 JSON 源码编辑，带有字段注释与热重载提示。
- **卡片精细化排版**：优化已安装模组卡片的信息层次与对齐，整合状态徽标、版本、支持平台与 SDK 门槛显示。
- **精简界面板块**：移除已下载模组包列表，列表聚焦于已安装模组与本地包导入。
