# Astral Party Toys Android 1.1.2

本次更新带来全面改版的应用界面，以及游戏内的半屏悬浮侧栏。

## 应用界面

- 全新排版：每页顶部为标题 + 说明，内容以圆角卡片分组，主题色与默认背景保持不变。
- 竖屏底部切换栏改为悬浮 Dock（横屏仍为左侧导航栏），列表末项不会被 Dock 遮挡。
- 设置页新增「背景」：可从相册选择图片作为应用背景，可一键恢复默认背景；所选图片会按最长边 2048 像素缩放后保存。

## 游戏内悬浮窗

- 由全屏面板改为半屏侧栏（横屏约占半屏宽、接近全高；竖屏接近全宽、约占半屏高），不遮挡对局信息。
- 首次打开默认进入「变速」页，倍数从 1.0x 起步；提供 -1 / -0.5 / +1 / +1.5 快捷调整，1.0x 时减速按钮置灰，范围限制在 1.0x - 10.0x。
- 「功能」页严格按分组展示：变速类仅 SpeedHackMod，隐藏类仅 HideHudMod，感谢/看板/预告类为 AutoThanksMod、ShopRelicPeekMod、PveWaveForecastMod，其余模组归入「其他」。
- 功能开关为真实开关，显示「已开启 / 已关闭」，点击即写入该模组配置并触发热重载，无需重启游戏。
- HUD 隐藏功能在配置未加载或隐藏范围为空时会明确提示失败原因，不会显示虚假的开启状态。
- 模组多为中文名称，面板内可滚动，支持返回上一级。

## 安装步骤

1. 安装本页的 `aspatoys-1.1.2.apk`。
2. 在设备上运行 Shizuku 并授权，打开应用进入「加载器」页。
3. 点「安装」或「更新加载器」，等待写入完成。
4. 点「安装 / 更新悬浮窗」，把内置悬浮窗同步到游戏侧。
5. **完全重启游戏**（从后台划掉进程）后进入对局，悬浮窗才会生效。
