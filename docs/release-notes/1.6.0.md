# Astral Party Toys Android 1.6.0

应用版本 1.6.0，versionCode 10600，沿用原正式签名，可从 1.1.2 及以上版本覆盖升级。

## 变更内容

- 新增「自定义主页背景」管理（位于自定义页）：支持导入静态图片与动态视频，自动按 720p / 1080p 预处理为流畅 H.264（保留 60fps 原帧率，含多级 EGL 配置降级与无损去音轨兜底）。
- 选择图片或视频时支持「从相册选择」与「从文件选择」两种来源。
- 导入主页背景前自动检测「自定义主页背景（HomeBackgroundMod）」安装状态与版本；未安装或版本过旧时可直接跳转模组市场安装/更新。
- 合并内置安卓悬浮窗 1.1.0 修复：消除展开/收起边角接缝与模糊、修复点击滚动回跳、字体缩放闪烁、收起位置漂移以及配置页过滤异常。

## 安装

1. 覆盖安装 `aspatoys-1.6.0.apk`。
2. 若需在游戏内使用主页背景功能，请在模组市场安装或更新 `HomeBackgroundMod`（推荐 1.2.1 及以上）。
3. 如从 1.4.x 及更早版本升级，请在加载器页重新安装一次加载器，然后完全重启游戏。
