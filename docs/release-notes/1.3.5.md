# Astral Party Toys Android 1.3.5

修复渠道服（含 Bilibili `com.feimo.astralparty.bilibili` 及所有 `com.feimo.astralparty.*` / `com.feimo.jxpd.*` 后缀包体）切换目录不同步、缓存解析与安装兼容问题。应用版本 1.3.5，versionCode 10305，沿用原正式签名。

## 修复与改进

- **渠道工作区同步**：切换游戏包名或首次启动检测到仅安装渠道服时，立即同步刷新「加载器目录」与模组列表，不再停留在官服 `com.feimo.astralparty` 路径；修复悬浮窗更新与外观同步在切换渠道后指向旧目录的问题。
- **UnityFS 缓存解析修复**：解压数据块时按规范使用 `block.flags & 0x3F` 掩码，修复带流式等高位标志的渠道缓存包报压缩方式未知的问题。
- **去除渠道检查对外部 `unzip` 的依赖**：原生加载器冲突检测改用纯 Kotlin ZIP 中央目录解析，避免在不含 `unzip` 命令的 Android 设备上中断渠道服安装。
- **强制兼容与运行引导增强**：
  - 本地程序集编辑遇到非重复注入类的结构/读取不兼容时，强制兼容开关可稳定回退到经校验的 3.3.0 兼容基准并重绑定目标渠道包名；
  - 引导入口与 `Boot.cs` 均支持按 `UnityEngine.Application.persistentDataPath` 自动兜底定位渠道目录，并将加载异常输出到 `UnityEngine.Debug.LogError` 便于诊断。

## 安装与使用

1. 覆盖安装本版 APK，完全退出游戏。
2. 授权 Shizuku 或切换 Root 模式，在「加载器」页确认已选中对应渠道包名并开启「实验性强制兼容渠道资源」。
3. 点击「安装内置加载器」，完成后完全重启游戏。若需还原，可禁用或卸载加载器恢复当前渠道原版缓存。
