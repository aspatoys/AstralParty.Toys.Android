# Astral Party Toys Android 1.2.4

基于 1.2.3 调整悬浮窗，沿用原签名，versionCode 为 10204。

- 参照用户截图，独立圆角侧栏与主框分开显示，中间留空隙；主框改为圆角正方形，与侧栏等高。
- 移除收起按钮，点击两块面板外的空白区域收起，继续把触摸交给游戏。
- 移除底角拖拽缩放。APK 保留统一大小和分组设置，宽高不再分别调整。
- 透明度移至游戏悬浮窗侧栏「设置」，即时调整并保存；APK 保存分组或大小时保留游戏中的最新透明度。
- 收起入口使用圆形遮罩。闲置 5 秒或点击外部后淡化并吸附屏幕边缘，半个图标隐藏在边缘外；触摸后唤醒，可继续拖动和展开。
- 变速页「恢复原速」会保存当前倍率并恢复 1.0x，随后显示「启用原变速」，再点恢复刚才倍率。此记忆仅保留在当前游戏会话，启动仍保持 1.0x。

安装后执行「加载器 → 安装 / 更新悬浮窗」，完全重启游戏。


独立开关动画：侧栏先滑出淡入，主框稍后缩放弹出；收起时主框先缩小淡出，侧栏随后退回。两条动画均使用真实时间，支持中途反向切换。未保存过透明度时默认 50%，已有保存值继续保留，可点恢复默认改为 50%。
