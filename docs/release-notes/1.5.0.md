# Astral Party Toys Android 1.5.0

加载器与 App 的程序集统一改到 Mobile 命名，一份加载器产物同时服务安卓与 iOS。应用版本 1.5.0，versionCode 10500，沿用原正式签名。

## 改名

- `CesiumLoader.Android.Bootstrap` → `CesiumLoader.Mobile.Bootstrap`：程序集名、命名空间与 `Boot` 入口类型一并改。
- `CesiumAndroidApi` → `CesiumLoader.Mobile.API`：程序集名、命名空间与产物文件名一并改。

`CesiumLoader.SDK` 名称不变，行为不变。

## 兼容性

- **已安装的设备需要重装加载器**：注入的引导按新的程序集名解析，旧补丁找不到它。
- **第三方模组需要重新编译**：任何按名字引用这两个程序集的模组，否则运行期会 `Could not load assembly`。

## 安装

1. 覆盖安装 `aspatoys-1.5.0.apk`，可沿同一证书从 1.1.2 起升级。
2. 在加载器页重新安装一次加载器（或导入同一个发布包），让新的引导与 API 落盘，然后完全重启游戏。
