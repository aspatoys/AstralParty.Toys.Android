# Astral Party Toys Android 1.2.0

新增「自定义」页面，首批提供卡牌方案管理，兼容 Win 版卡牌方案 ZIP。

## 卡牌自定义

- 底部 Dock 与横屏侧栏增加「自定义」，本版仅包含「卡牌」。
- 导入 Win 版导出的卡牌方案 ZIP；支持普通方案目录、根目录图片和 `AstralParty_ModLoader/skins/` 完整目录结构。
- 显示方案名称、作者、卡面数量与选择状态；可创建方案、搜索卡牌、替换单张卡面、恢复原图、删除及导出方案。
- 保留 Win 版素材名、数字 ID、中文卡牌名称与 SFW 卡面匹配方式。未替换的卡面保留游戏原图。
- 动态卡面使用 Win 版的 `.cardanim` 清单和 `.frames` PNG 序列；导出的 ZIP 也可交给 Win 版使用。
- 方案通过 Shizuku 或 Root 写入当前游戏的加载器目录；应用时更新卡面模组，并保留其他模组和既有配置。

## 使用步骤

1. 安装 `aspatoys-1.2.0.apk`，在「加载器」连接 Shizuku 或 Root；首次使用需先安装加载器。
2. 进入「自定义 → 卡牌」，点「导入方案 ZIP」，选择 Win 版导出的卡牌方案。
3. 点方案的「应用」，等待完整写入后，**完全退出并重新启动游戏**。
4. 修改单卡后再次应用方案；恢复游戏原图可点「恢复默认」。

本版不包含音效、角色、资源包或背景方案移植。游戏内悬浮窗和 1.1.4 已有功能继续保留。

## 签名与升级

1.2.0 沿用 1.1.2 的正式私钥签名，支持从使用同一证书的 1.1.2–1.1.4 覆盖升级。按用户选择，公开验证证书和 RSA 公钥，不公开私钥。

- APK 证书 SHA-256：`7cdb0644cd2bc4370152643950dde7b8cbf99ba4f770e094e9ecb775ca392bcc`
- `aspatoys-signing-certificate.pem`：验证证书。
- `aspatoys-signing-public-key.pem`：验证公钥。
- 验证方法见仓库 `docs/signing/README.md`。

早期正式版 1.1.0 / 1.1.1 及测试包签名不同，不能直接覆盖，需要先保存设置、卸载旧版再安装。
