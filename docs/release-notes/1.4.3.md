# Astral Party Toys Android 1.4.3

随包加载器升级到 CesiumLoader 4.1.1，并在 Release 里多挂一个托管载荷包，让需要引导 DLL / SDK 的工具不用再解压 APK。应用版本 1.4.3，versionCode 10403，沿用原正式签名。

## 加载器

- 随包升级到 CesiumLoader `4.1.1`：没有 Win32 原生后端的平台上，SDK 的输入后端会退回 Unity 反射实现，不再让用到热键的模组每帧抛异常、把游戏卡在大厅；音频的原生后端拿不到时也走同一条退路。
- 更新加载器时仍然同时替换安卓引导、SDK 与内置模组，三者来自同一个 App 版本。

## 发布资产

- 新增 `cesium-loader-android-managed-<版本>.zip`，内容是 `bootstrap/CesiumLoader.Android.Bootstrap.dll`、`sdk/CesiumLoader.SDK.dll`、`CesiumAndroidApi.dll` 与 `loader.json`，并附带 `.sha256`。
- `version.json` 增加 `packages.loaderManaged`（文件名 / 地址 / SHA-256 / 大小）：需要引导 DLL 的工具直接下这个小包即可，不必再解压完整的 APK。

## 安装

1. 覆盖安装 `aspatoys-1.4.3.apk`，可沿同一证书从 1.1.2 起升级。
2. 在加载器页重新安装一次加载器（或导入同一个发布包），让新的 SDK 与引导落盘，然后完全重启游戏。
