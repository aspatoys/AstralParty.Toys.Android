# Astral Party Toys Android 1.4.0

新增「选择目标游戏」应用列表与首次使用引导，安装与更新加载器时显示明确进度。应用版本 1.4.0，versionCode 10400，沿用原正式签名。

## 选择目标游戏

- 加载器页的「游戏资源」改为**应用列表**：从系统已安装应用中选择要安装加载器的游戏。默认官方包 `com.feimo.astralparty` 置顶，已知渠道服与共存版排在前面，每行显示应用名、包名与版本号。
- 默认列出**全部应用**，可用「推荐」缩小到可能是游戏的那几个，也可搜索应用名或包名。
- 列表里没有的包仍然可以选：可以从文件夹选择，或者直接手动输入包名。
- 每行标注「默认 / 已装加载器 / 未收录渠道」，哪个包已经装过加载器一眼可见。

## 当前目标标记

- 模组页与加载器页的标题下方常驻「正在管理 〈应用名〉〈包名〉」标记；不在加载器已知渠道规则内的包使用警示色并标出「未收录渠道」，点一下即可切换目标。
- 加载器安装 / 卸载 / 恢复原版的确认弹窗第一行写明目标游戏；进度面板的标题也会带上目标应用，切换渠道后不会改错对象。
- 设置页「加载器根目录」显示当前管理的应用名与包名。

## 首次使用引导

- 没装过加载器时打开应用进入引导：说明 → 选择目标游戏（只选一个）→ 授权 Shizuku / Root → 安装内置加载器 → 完成。
- 引导可以跳过，也可以中途退出；已经装过加载器的用户不会看到引导。
- 同一时间只管理一个游戏，之后可随时在加载器页或设置里切换。

## 加载器更新与导入

- 校验并解压发布包时按文件上报进度（`正在校验并解压发布包 i / n`），这一步不再长时间停在同一条提示上。

## 安装

1. 覆盖安装 `aspatoys-1.4.0.apk`，可沿同一证书从 1.1.2 起升级。
2. 已安装的加载器、模组、配置与卡牌方案保留在加载器目录，无需重新导入。
3. 首次安装后按引导选择目标游戏并授权，装完完全退出再重启游戏。
